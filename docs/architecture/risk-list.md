# Review triggers

| Assumption | Trigger | Response |
|---|---|---|
| Upstream v0.4.0 contracts remain stable | Dependency or tag change | Re-run full upstream regressions and seam tests |
| Compressed output retains core evidence | Support/citation score falls | Inspect the omitted facts and revise context strategy |
| Frozen tools cover valid market/news requests | Frequent unavailable results for present data | Correct the corpus adapter rather than inventing results |
| Single operator uses ledger sequentially | Network service or concurrent execution added | Revisit transaction isolation and identity architecture |
| Model usage is reported | Missing usage or provider schema change | Stop aggregate cost claims and repair metering |
| Private GitHub account supports protection | Protection API refuses | Preserve evidence and disclose missing external enforcement |

These triggers bound meaningful engineering work. They do not justify speculative frameworks or endless defensive tests.
