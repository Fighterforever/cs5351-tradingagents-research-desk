# Option ledger

| Option | Decision | Reason | Revisit when |
|---|---|---|---|
| Web frontend | Deferred | The CLI and generated Markdown reports cover the complete operator workflow | Repeated user research shows CLI prevents use |
| Exact recorded tool-response lookup for controlled reruns | Rejected after inspection | Different valid tool arguments must still read the same corpus | Only replaying an identical transcript, without a live model |
| Compress only past memory | Rejected for experiment | Fresh cases have empty memory, so dominant prompt cost is unchanged | Longitudinal runs supply substantial prior memory |
| Replace research graph with two agents | Rejected | Violates extension scope and baseline comparability | A separately approved architecture study |
| Broker connection | Excluded | Course safety boundary is demonstrated by paper state | A new application with authentication and operational controls |
| Require paid GitHub plan | Excluded | User authorized a private deliverable, not a purchase | Explicit later authorization |
