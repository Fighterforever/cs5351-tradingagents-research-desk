# Research Desk CI gates

Decision owner: leo. The workflow is `.github/workflows/ci.yml`. OpenCode generated the check scripts; the coordinating workflow reviewed their behavior against the approved requirements and actual source interfaces. The six independent jobs are intended required checks for the private repository. Server-side branch protection is recorded separately after GitHub accepts or rejects the configuration request.

| Gate | Blocking contract | Local command |
|---|---|---|
| 1. Tests approved before implementation | A scoped approval names the test/plan versions, covers AT-01 through AT-08, and predates implementation. Changed tests need a corresponding approval update. | `python scripts/check_approval.py` |
| 2. Static and authority checks | Repository lint, application type checks and dependency consistency succeed. Deterministic policy owners cannot acquire LLM authority. Safety changes carry changed decision evidence. | `python scripts/check_static.py` |
| 3. Requirements and traceability | The real YAML registry satisfies its JSON schema; requirement IDs and source/component/test mappings remain consistent. | `python scripts/check_requirements.py` |
| 4. Fixed semantic regression | Replay fixed captured packs without networking and exercise the real compact transform on the six fixed source cases. Required facts and tool protocol remain intact. | `python scripts/check_semantic.py` |
| 5. Regression | Both the preserved upstream `tests/` suite and application `test/offline/` suite succeed. Live API experiments are recorded separately. | `python scripts/check_regression.py` |
| 6. AI-use log | A code or prompt change updates the log with a real session and a scope that covers the changed files. | `python scripts/check_ai_use_log.py` |

The workflow uses Python 3.12 and installs dependencies with the existing `requirements-lock.txt` as pip constraints. Mypy checks `src/research_desk` with imports outside that package skipped; the unchanged upstream project remains covered by its original tests and lint. No gate requires provider credentials. The semantic check measures deterministic input transformation and captured-output replay. The six-case live quality comparison uses separate actual provider calls and saved judgments; its results must not be inferred from an offline CI pass.

The scripts accept a repository root and explicit changed-file input for controlled negative demonstrations. PR runs derive the change set from GitHub's base and head revisions. A failed Git query fails change-dependent gates. A new branch's all-zero `before` value selects the preserved upstream `v0.4.0` tag, so inherited source is excluded from the project's AI-change accounting.
