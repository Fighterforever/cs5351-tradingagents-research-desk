## 3. Architecture Candidate Evaluation and ADR Traceability

The candidate analysis in [`../architecture/evaluation-table.md`](../architecture/evaluation-table.md) and [`../architecture/option-ledger.md`](../architecture/option-ledger.md) evaluates three options across five weighted criteria (`0.25` baseline preservation, `0.25` authority boundary, `0.20` evidence capture completeness, `0.15` single-operator scope fit, and `0.15` upstream maintainability). Recalculation confirms the weighted totals:

- **Candidate A (Edit core graph): `3.10`** — `0.25(3) + 0.25(3) + 0.20(5) + 0.15(2) + 0.15(2) = 3.10`. Direct internal edits maximize raw capture access (`5`) at the cost of baseline preservation (`3`), authority isolation (`3`), delivery scope (`2`), and upstream maintainability (`2`).
- **Candidate B (Application seams — Selected): `4.65`** — `0.25(5) + 0.25(5) + 0.20(4) + 0.15(4) + 0.15(5) = 4.65`. Wrapping `TradingAgentsGraph` via `EvidenceTradingGraph` and `GroundingDelegate` while isolating `review.py`, `policy.py`, and `storage.py` preserves unmodified upstream behavior (`INH-001`–`INH-005`: `5`), enforces a deterministic execution boundary (`INV-001`, `INV-002`: `5`), and closes direct identity/returns capture gaps via narrow overrides (`4`).
- **Candidate C (Replacement demo): `3.10`** — `0.25(1) + 0.25(4) + 0.20(4) + 0.15(5) + 0.15(2) = 3.10`. Replacing the multi-agent graph minimizes implementation effort (`5`) while failing inherited baseline requirements (`INH-001`–`INH-005`: `1`) and removing the multi-agent workload required for `FR-003` and `COST-001`.

Four ADR iterations trace the design refinements across the build and evaluation phases:

1. **[`../architecture/adr/001-application-extension.md`](../architecture/adr/001-application-extension.md) (with [`../architecture/adr/ADR-001-evidence-pack-format.md`](../architecture/adr/ADR-001-evidence-pack-format.md))**: Established `EvidenceTradingGraph`, `EvidencePackIO`, offline replay, and `GroundingDelegate` grounding injection across plain, tool-bound, and structured-output calls ([`../../src/research_desk/graph_adapter.py`](../../src/research_desk/graph_adapter.py), [`../../src/research_desk/evidence.py`](../../src/research_desk/evidence.py), [`../../src/research_desk/replay.py`](../../src/research_desk/replay.py), [`../../test/offline/test_at01_replay.py`](../../test/offline/test_at01_replay.py), [`../../test/offline/test_common_grounding_delegate.py`](../../test/offline/test_common_grounding_delegate.py)).
2. **[`../architecture/adr/002-exact-approval-and-total-position.md`](../architecture/adr/002-exact-approval-and-total-position.md)**: Bound approval fingerprints to exact share quantity, evidence price, and evidence ID; enforced the 10% equity cap on cumulative post-buy holdings; and permitted risk-reducing sales of existing holdings ([`../../src/research_desk/policy.py`](../../src/research_desk/policy.py), [`../../src/research_desk/review.py`](../../src/research_desk/review.py), [`../../test/offline/test_at03_ledger_approve.py`](../../test/offline/test_at03_ledger_approve.py), [`../../test/offline/test_at04_reject_boundaries.py`](../../test/offline/test_at04_reject_boundaries.py), [`../../test/offline/test_at05_version_recheck.py`](../../test/offline/test_at05_version_recheck.py)).
3. **[`../architecture/adr/003-effective-agent-permissions.md`](../architecture/adr/003-effective-agent-permissions.md)**: Synchronized `.opencode/permissions.jsonc` with root `opencode.json` role definitions, pinned the offline JSON schema registry, and verified runtime write denial on protected governance paths ([`../architecture/permission-model.md`](../architecture/permission-model.md), [`../../scripts/check_permissions.py`](../../scripts/check_permissions.py), [`../../scripts/check_static.py`](../../scripts/check_static.py), [`../../transcripts/project-permissions.full.json`](../../transcripts/project-permissions.full.json), [`../../transcripts/project-permission-probe.full.json`](../../transcripts/project-permission-probe.full.json)).
4. **[`../architecture/adr/004-release-quality-and-context-budget.md`](../architecture/adr/004-release-quality-and-context-budget.md)**: Made `REJECTED` proposal status terminal on execution attempts, enforced the 72,000/96,000-unit whole-input context budget (`CTX-001`), rendered deterministic evidence headers (`QUALITY-001`), enforced earnings-period semantics (`QUALITY-003`), bound release quality gate validation to SHA-256 runtime source fingerprints (`GOV-003`), and configured `reasoning_effort: "none"` in DeepSeek `extra_body` ([`../../src/research_desk/review.py`](../../src/research_desk/review.py), [`../../src/research_desk/budget.py`](../../src/research_desk/budget.py), [`../../src/research_desk/eval/compact_delegate.py`](../../src/research_desk/eval/compact_delegate.py), [`../../src/research_desk/eval/quality.py`](../../src/research_desk/eval/quality.py), [`../../test/offline/test_revision_contracts.py`](../../test/offline/test_revision_contracts.py), [`../../test/offline/test_context_budget.py`](../../test/offline/test_context_budget.py), [`../../test/offline/test_release_quality.py`](../../test/offline/test_release_quality.py)).
